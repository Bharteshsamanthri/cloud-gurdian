# Cloud Guardian
## AWS Cloud Operations Monitoring System

Cloud Guardian is a cloud operations learning project focused on Linux server monitoring, automation, and infrastructure management.

### Technologies
- AWS EC2
- Ubuntu Linux
- Bash scripting
- systemd
- HTML and CSS
- Amazon CloudWatch (planned)
- Amazon SNS (planned)

### Features
- System health-check script
- Linux service configuration
- Automated monitoring schedule configuration
- Project website
- Cloud operations documentation

### Project Structure
- index.html: Project website
- scripts/health-check.sh: System health checks
- systemd/: Service and timer configurations
- docs/: Architecture documentation

### Future Improvements
- Integrate CloudWatch metrics and alarms.
- Add SNS email notifications.
- Display live server metrics.
- Implement service failure detection.

### Security
Never upload AWS credentials, private keys, passwords, or access tokens.

### Project Status
This project is under development. Cloud integrations and live monitoring must be configured and tested before being described as operational.
